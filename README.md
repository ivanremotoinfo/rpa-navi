# Gerador RPA

Calculadora e gerador de texto de Recibo de Pagamento Autônomo (RPA) para escritórios de advocacia.

Calcula automaticamente:
- **INSS** (11% sobre o valor bruto, contribuinte individual, limitado ao teto de R$ 932,31/mês — 2026)
- **IRRF** (tabela progressiva mensal 2026 + redução da Lei 15.270/2025)
- **ISS** (opcional, alíquota configurável)

Gera um recibo por mês para o período de competência informado, com valor por extenso, pronto para copiar e assinar.

Abra o `index.html` no navegador — não precisa de instalação nem de servidor. Os dados do contratante e do prestador ficam salvos apenas no navegador de quem usa (localStorage).

> Cálculo estimado conforme a legislação vigente em 2026. Confirme os valores com a contabilidade antes de reter em um pagamento real.
